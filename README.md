# 🎓 StudentBag - حقيبة الطالب

## 📌 نبذة عن المشروع
**StudentBag** هو تطبيق أندرويد يهدف إلى مساعدة طلاب الجامعات في تنظيم حياتهم الأكاديمية من خلال إدارة المواد الدراسية والمهام والخطط الدراسية والملخصات باستخدام Kotlin وFirebase وRoom Database.

## 📖 الوصف المختصر
تطبيق أندرويد لتنظيم وإدارة الحياة الأكاديمية للطالب داخل منصة واحدة سهلة الاستخدام.

## 🎯 أهداف المشروع
- تنظيم المواد الدراسية.
- إدارة الواجبات والمهام.
- إنشاء خطة دراسية.
- إنشاء وإدارة الملخصات.
- متابعة الأداء الأكاديمي.

## ❓ المشكلة التي يعالجها المشروع
يجمع التطبيق جميع الأدوات الأكاديمية في مكان واحد لتسهيل متابعة الدراسة وتقليل تشتت المعلومات.

## 📱 نوع المشروع
Android Mobile Application

## ⚙️ التقنيات المستخدمة
- Kotlin
- Android SDK
- XML
- Jetpack Compose
- Firebase Authentication
- Firebase Firestore
- Room Database
- Gradle Kotlin DSL
- Android Studio
